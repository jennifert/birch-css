# Birch CSS

A personal fork of [Pico CSS](https://github.com/picocss/pico),
based on version 2.1.1, with additional components and changes
for my own projects.

You're welcome to use it, but development follows my needs.
There is no commitment to support, feature requests, or a
release schedule.

For other continuations of Pico CSS, explore its
[community forks](https://github.com/picocss/pico/forks),
including [Blades](https://github.com/anyblades/pico-is-now-blades).
Evaluate those projects for your own requirements.

Built on Pico CSS. The original code retains its copyright
notices and MIT license. Birch CSS is independent of and
not affiliated with Pico CSS.
